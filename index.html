Fourteen question types, one message out

Mix and match short text, choices, media and contact fields — WateForm formats the final message for you.

Short text

Long text

Multiple choice

From blank form to a message in someone's chat

Four steps, in order — this is genuinely the sequence, not decoration.

1

Create a workspace

Give it a name, invite teammates by username, and everyone in it can build and read responses together.

2

Build the form

Drag in question types, write the copy, set which ones are required — a live preview updates as you go.

3

Point it at WhatsApp or Telegram

Add a phone number, a Telegram username, or both. Pick the language and the text on the submit button.

4

Publish and share the link

wateform.my.id/<code>

goes live. Every completed reply arrives as a message — no inbox to check.
